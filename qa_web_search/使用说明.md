# qa_web_search 使用文档

## 一、技能定位

`qa_web_search` 是一个面向 QA 与情报检索场景的搜索技能，支持：

- Bing / Google 关键词搜索
- 深度页面结构提取
- 检索过程截图留证

## 二、快速开始

```bash
# 关键词搜索
./qa_web_search "openai当前推出的最新模型是什么" --num 5 --engine bing

# 深度页面提取
./qa_web_search --deep https://docs.openclaw.ai

# 带截图
./qa_web_search "日本现任首相是什么" --engine bing --screenshot /tmp/japan-pm.png
```

## 三、常用参数

- `--engine bing|google`：指定搜索引擎
- `--num N`：返回结果数量
- `--deep <url>`：深度页面分析
- `--screenshot <path>`：保存当前页面截图
- `--fullpage`：整页截图

## 四、结果输出

输出为 JSON，核心字段包括：

- `tool`
- `mode`
- `total`
- `results[]`（搜索模式）
- `page / links / forms / buttons / meta`（深度模式）

## 五、建议实践

1. 事实问答：优先 `bing`，并追加 `--screenshot` 留证
2. 页面取证：使用 `--deep + --fullpage`
3. 稳定性验证：固定回归词条（人物、机构、版本号）每日冒烟
