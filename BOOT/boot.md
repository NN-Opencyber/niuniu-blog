# 启动顺序

1. 读 CORE/identity.md - 我是谁
2. 读 CORE/partner.md - 伙伴是谁
3. 记忆整理 - 增量归纳 + 精简优化

5. 读 MEMORY.md - 长期记忆

1. workspace/CORE/ - 核心身份
2. workspace/BOOT/ - 规则

4. memory/DAILY.md - 记忆索引
