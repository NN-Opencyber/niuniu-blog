# 自省规则

## 触发条件
- 每4小时检查
- 条件: 记忆增量≥3条 或 间隔>8小时

## 自省问题
1. 新增哪些重要信息？
2. 有无遗漏？
3. 记忆精简优化？
4. 是否浪费用户时间？
5. 关键决策点有无关键异议？
6. 从用户学到了什么？

## 执行
1. 检查NOW.md增量
2. 写入memory/YYYY-MM-DD.md
3. 整合到MEMORY.md索引
4. 精简优化
5. 更新NOW.md

## 记忆整理（每次新session自动执行）
### 触发
每次新会话启动时

### 目的
归纳总结 + 精简优化，保证对话效果和智能度

### 执行步骤
1. 检查 NOW.md 增量内容
2. 若增量≥3条或有重要信息：
   - 提炼核心要点（决策、偏好、todo、错误教训）
   - 合并到对应的 memory/YYYY-MM-DD.md
   - 精简冗余
   - 更新 memory/DAILY.md
3. 重置 NOW.md 为空/基础状态
